Jamie's Tunes Master Ruleset

Effective Date: August 30, 2026 — Consolidated & Updated Standards

1. File Reference & Naming Standard

  • Mandatory First-Line Comment: Every HTML file created or modified across all domains must include a comment on the very first line containing the full file URL (including the .html extension) for precise reference (e.g., <!-- https://jamiestunes.com/geminirules083026.html -->).
  • Timestamp Line: The second line of every HTML file must state the exact timestamp to the minute alongside the date (e.g., <!-- August 30, 2026 — 7:38 PM MDT -->).

2. Component Architecture & Fetching

  • Dynamic Slot Fetching: Navigation sidebars, headers, and footers must be modularly inserted via client-side JavaScript fetch() calls targeting shared slot elements (#sidebar-slot, #header-slot, #footer).
  • Local Storage Counters: Page view counters must utilize client-side browser localStorage logic embedded directly inside fetched footer components rather than depending on external Cloudflare Workers.

3. Styling & Layout Guidelines

  • Inline & Internal CSS: Prefer structured internal CSS within standalone full-page HTML structures, utilizing inline styling for specialized element tweaks. Avoid external CSS dependencies where possible.
  • Color Palette: Maintain dark-themed aesthetics featuring deep backgrounds (#121212, #1a1a1a), high-contrast white text, electric blue headings (#1e90ff), and gold accent headers (gold).
  • Artist Banner Sizing: Artist banner images in directory profiles must be set to 640px width (or 50% scale relative to native high-res source images) with max-width: 100% and height: auto for responsive scaling.

4. URL & Link Standards

  • No-WWW Absolute Paths: All internal and external navigation links must enforce absolute URLs without the "www" subdomain across all domains (e.g., jamiestunes.com).
  • Verified Media Embeds: All YouTube iframe embeds in artist directories must utilize verified working video IDs matching the standard Responsive Video Container structure (`.video-container`) to prevent broken playback.
